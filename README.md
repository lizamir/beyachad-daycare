# ביחד — ניהול משפחתון

אפיון וסקיצה אינטראקטיבית לאפליקציה בעברית לניהול משפחתון של כ־10 ילדים, עם חשבונות נפרדים למנהלת, לצוות ולהורים. השם ״ביחד״ זמני.

## מצב הפרויקט

זהו אב־טיפוס לתכנון המוצר, ולא אפליקציה מוכנה לשימוש או להפצה בחנויות. הנתונים מומצאים. החלפת תפקיד בסקיצה היא הדגמה בלבד: אין אימות זהות, שרת נתונים, אכיפת הרשאות, סליקה, הפקת חשבוניות או זיהוי פנים.

## צפייה מקומית

מהתיקייה הראשית של הריפוזיטורי:

```sh
python -m http.server 5173 --bind 127.0.0.1
```

פתחו `http://localhost:5173/`. ניתן גם לפתוח את `index.html` ישירות בדפדפן. אין צורך בהתקנת חבילות.

## יעד המוצר

אפליקציה ל־Android ול־iPhone, בעברית ובכיווניות מימין לשמאל. מתחילים במשפחתון; בעתיד ניתן להרחיב למעון ולגנים. טרם נבחרה טכנולוגיית הפיתוח. קובצי HTML כאן משמשים להמחשת הממשק בלבד.

## כללי עבודה

יש לשמור רק נתונים פיקטיביים בריפוזיטורי. אין להעלות פרטי ילדים, תמונות אמיתיות, מסמכים כספיים, מפתחות API או סודות. אין רישיון קוד פתוח שנבחר בשלב זה.
